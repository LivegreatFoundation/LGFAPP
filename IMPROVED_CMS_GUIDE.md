## 🎯 **How to Use the New System**

### **Step 1: Access the Admin Panel**
1. Go to: `http://localhost:8000/admin/`
2. Login with your credentials:
   - Username: `lucie`
   - Password: `luciepassword`

### **Step 2: Navigate to Website Content**
1. In the admin panel, look for **"Website Content"**
2. Click on it to see all your website content organized clearly

### **Step 3: Understanding the Content List**
You'll see a table with columns:
- **Content Section**: Shows exactly where this content appears (e.g., "🏠 Home: Main Hero Section")
- **Page**: Which page it belongs to (Home, About, Programs, etc.)
- **Heading Preview**: A preview of the heading
- **Content Preview**: A preview of the main content
- **Image**: Shows if there's an image attached
- **Active**: Whether this content is currently shown on the website
- **Display Order**: The order in which content appears

### **Step 4: Editing Content**
1. **Click on any content item** to edit it
2. You'll see organized sections:
   - **📍 Content Location**: Shows where this appears on your website
   - **📝 Content**: The actual text and images visitors will see
   - **⚙️ Display Settings**: Control when and how it's shown

### **Step 5: Adding New Content**
1. Click **"Add Website Content"** button
2. Choose the **Page** (Home, About, Programs, Team, Contact)
3. Choose the **Content Type** from the dropdown (all options are clearly labeled)
4. Add your **Heading** and **Content**
5. Upload an **Image** if needed
6. Set **Display Order** (lower numbers appear first)
7. Make sure **Is Active** is checked to show it on the website
